## 🎯 Sobre o Projeto

Mais do que uma página de apresentação, este portfólio reflete a minha mentalidade arquitetural e foco em performance. O layout foi idealizado no formato *"Executive BI View"*, adotando o *Corporate Dark Modernism* para garantir uma experiência imersiva, elegante e corporativa.

Nele, você encontrará:
- **A Jornada do Dado:** Minha visão arquitetural desde a Governança e Ingestão de Dados até a Engenharia Analítica.
- **Ecossistema Personal JobTracker:** Um case *end-to-end* demonstrando o fluxo real de BI usando Power Automate, Azure SQL, Power Query (Linguagem M) e Power BI (DAX).
- **Formação e Certificações:** Validações do meu background, incluindo foco nas certificações Microsoft PL-300 e DP-600.

## 🛠️ Stack Tecnológica (Frontend)

Embora meu foco principal seja a engenharia de dados, apliquei boas práticas de desenvolvimento de software para construir esta interface *Serverless*:

- **HTML5 & CSS3:** Semântico e responsivo.
- **Tailwind CSS:** Framework utilitário para estilização avançada, gerenciamento de gradientes neon, tipografia corporativa e efeitos "Glassmorphism" (efeito vidro).
- **Node.js (NPM):** Gerenciamento do build do Tailwind e dependências.
- **GitHub Pages / Azure Static Web Apps:** Deploy contínuo (CI/CD) e hospedagem em nuvem estática.

## ⚙️ Como executar localmente

Se você deseja clonar ou rodar este projeto em sua máquina local para testes:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/GabrielVieiraDL/seu-repositorio.git
   cd seu-repositorio
   ```

2. **Instale as dependências (Tailwind CLI):**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento e o build automático do CSS:**
   ```bash
   npx tailwindcss -i ./src/style.css -o ./dist/output.css --watch
   ```

4. **Abra o arquivo `index.html`** no seu navegador preferido ou utilize a extensão *Live Server* do VS Code.
