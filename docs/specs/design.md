## Brand & Style

This design system establishes a high-performance, precision-engineered visual aesthetic for an advanced Analytics Engineering and Data Architecture portfolio. The experience balances corporate executive rigor with technical fluency, projecting architectural mastery, computational authority, and clarity across complex data ecosystems.

The visual direction merges **Corporate Dark Modernism** with **Analytical Glassmorphism**:
- **Atmosphere:** Deep obsidian and charcoal navy depths evoking high-end command centers and computational consoles.
- **Accents:** Electric neon cyan and concentrated royal blue delivering focused luminescent signals, indicative of active pipelines, query executions, and high-signal metrics.
- **Structure:** Clean tabular alignment, generous whitespace, structured grid lines, and high-density metric indicators designed for technical decision-makers (VPs of Data, Head of Engineering, and Chief Analytics Officers).

## Colors

The palette is tuned specifically for deep-dark displays, optimizing contrast ratios for code artifacts, lineage graphs, and executive metric summaries.

### Canvas & Surface Architecture
- **Root Canvas (`#0B0F19`):** Deep charcoal navy anchoring the lowest viewport level.
- **Surface Elevation 1 (`#0F172A`):** Structural panels, sidebars, and base card surfaces.
- **Surface Elevation 2 (`#1E293B`):** Interactive containers, table headers, and modal dialogs.
- **Border Surface (`#334155` at 40% to 70% opacity):** Structural hairline separators.

### Brand & Luminescence Accents
- **Primary Cyan (`#00E5FF`):** Reserved for primary interactive states, pipeline status indicators, code highlight tokens, and active execution anchors.
- **Secondary Royal Blue (`#3B82F6`):** Applied to structural branding elements, secondary actions, and linked pipeline stages.
- **Tertiary Dark Cyan (`#06B6D4`):** Supporting data points, intermediate state tags, and analytical metadata.

### Typography & Readability Neutrals
- **Text Primary (`#F8FAFC`):** Crisp ice white for high-priority headings, metric figures, and core copy.
- **Text Secondary (`#94A3B8`):** Muted slate for descriptive paragraphs, labels, and table column keys.
- **Text Muted (`#64748B`):** Diminished slate for timestamps, system metadata, and disabled UI states.

## Typography

Typography establishes an immediate hierarchy between executive narrative and technical implementation:
- **Headings & Impact Metrics (`Plus Jakarta Sans`):** Clean, structural geometric construction with tightened tracking (`-0.02em` to `-0.03em`) to project clarity and executive impact.
- **Long-form & UI Copy (`Inter`):** Systematic, highly legible neutral grotesque engineered for extended reading across complex technical case studies and architectural rationales.
- **Engineering Metadata & Lineage Nodes (`JetBrains Mono`):** Monospaced type for data pipeline orchestration tags, schema names, latency measurements, and code snippets. Always set with positive letter spacing (`0.04em` to `0.06em`) when rendered in uppercase.

## Layout & Spacing

The layout model adheres to a rigorous **12-column fluid grid** system bounded by a maximum content container width of `1280px` (`80rem`):
- **Desktop (>= 1024px):** 12 columns with `1.5rem` gutters and `3rem` canvas margins. Case studies leverage asymmetric splits (7 columns for pipeline diagrams, 5 columns for narrative outcomes).
- **Tablet (768px - 1023px):** 8 columns with `1.25rem` gutters and `2rem` canvas margins.
- **Mobile (< 768px):** 4 columns with `1rem` gutters and `1.25rem` outer margins. Multi-column metric arrays collapse into 2-column or single-column data cards.

Vertical rhythm follows a strictly maintained 8px baseline (`space-xs` through `space-2xl`), enforcing balanced whitespace around dense analytical components.

## Elevation & Depth

Visual hierarchy is communicated through **Translucent Glassmorphism**, layered depth planes, and controlled perimeter luminescences rather than blunt drop shadows.

1. **Floor Level (Canvas):** Pure `#0B0F19` with a subtle radial gradient of Royal Blue (`rgba(59, 130, 246, 0.05)`) focused at the page header.
2. **Layer 1 (Card & Module Surfaces):** Background fill of `rgba(15, 23, 42, 0.65)` layered with `backdrop-filter: blur(16px)` and a precise hairline border of `rgba(148, 163, 184, 0.1)`.
3. **Layer 2 (Interactive Floating Elements & Modals):** Background fill of `rgba(30, 41, 59, 0.85)` with `backdrop-filter: blur(24px)` and a dynamic border glow of `rgba(0, 229, 255, 0.25)`.
4. **Active Luminescence (Hover & Status Signals):** High-priority cards project an ambient boundary aura on hover: `box-shadow: 0 0 24px -4px rgba(0, 229, 255, 0.12), inset 0 0 0 1px rgba(0, 229, 255, 0.4)`.

## Shapes

The design system enforces a **Soft Structural (`1`)** shape language, maintaining the rigorous discipline of enterprise data infrastructure:
- **Base Elements (Buttons, Inputs, Badges):** `0.25rem` (4px) border radius for crisp, technical definition.
- **Structural Modules (Cards, Visualizations, Lineage Panels):** `0.5rem` (8px) border radius (`rounded-lg`), providing separation without softening into consumer-app aesthetics.
- **Overlays & Code Modals:** `0.75rem` (12px) border radius (`rounded-xl`).
- **Pill Exceptions:** Restricted strictly to operational status indicators (e.g., active pipeline state `99.9% uptime`) using full round caps (`9999px`).

## Components

### Buttons
- **Primary:** Solid electric cyan `#00E5FF` text on dark `#0B0F19` background or high-impact primary fills using gradient `linear-gradient(135deg, #00E5FF, #3B82F6)` with dark ink text `#0B0F19` in `Plus Jakarta Sans` semi-bold. Micro-glow shadow: `0 0 16px rgba(0, 229, 255, 0.35)`.
- **Secondary (Ghost Outline):** `1px` border of `rgba(148, 163, 184, 0.2)` over `rgba(15, 23, 42, 0.5)` glass surface. Text in `#F8FAFC`. On hover: border shifts to `#00E5FF` with `rgba(0, 229, 255, 0.08)` fill.

### Metric KPI Badges & Technology Chips
- **Tech Stack Badges (dbt, Snowflake, Airflow, SQL):** Background `rgba(30, 41, 59, 0.7)`, border `1px solid rgba(148, 163, 184, 0.15)`, text `JetBrains Mono` at `11px`, colored in `#94A3B8`. Left-accented with a `4px` dot in `#00E5FF` or `#3B82F6`.
- **Status Chips:** Inset pill shape with pulse animation dot. Active: `#00E5FF` glow; Staging: `#3B82F6`; Warning/Maintenance: `#F59E0B`.

### Analytics Cards & Lineage Viewers
- **Glass Card Containers:** Frosted surfaces with low-contrast borders. Top right contains technical metadata tags (e.g., latency, run frequency) in `label-sm`.
- **Hover State:** Border color activates from static slate to linear gradient of `rgba(0, 229, 255, 0.5)` and `rgba(59, 130, 246, 0.5)`.

### Form Fields & Query Filters
- **Inputs:** Surface `#0F172A` with `1px` border `#334155`. Text in `#F8FAFC`, placeholder in `#64748B`. Focused state illuminates border with `#00E5FF` and applies a soft outer glow `0 0 0 3px rgba(0, 229, 255, 0.15)`.

### Code & Pipeline Lineage Blocks
- **Lineage Display:** Dark monospaced blocks featuring syntax highlighting against `#0B0F19` insets, complete with hairline connector lines rendered in `rgba(0, 229, 255, 0.3)` to indicate DAG (Directed Acyclic Graph) relationships.
